# 知网（CNKI）检索关键词
> 项目：基于 Spring Boot + Vue3 的校园社团成果展示与孵化系统
> 要求：2023–2026 年文献、共 20 条（含 3 条英文）、文献类型 ≥3 种

## 一、知网高级检索式（可直接粘贴到「高级检索」）

> 在知网高级检索里，字段选「主题 / 篇名 / 关键词」，多个词用「并含(AND) / 或含(OR)」。
> 下面 `*` 表示「并含」，`+` 表示「或含」。

**1. 社团管理系统主干（最核心，先跑这个）**
```
主题 = 社团 * （管理系统 + 信息管理系统 + 管理平台 + 管理系统设计与实现）
```

**2. 高校/学生社团 + 系统/平台**
```
篇名 = （社团 + 学生社团 + 高校社团） * （系统 + 平台 + 小程序 + 管理系统）
```

**3. 微信小程序方向**
```
主题 = （微信小程序 + 小程序） * （社团 + 校园 + 学生管理 + 高校管理）
```

**4. 后端技术方向（Spring Boot / Vue）**
```
主题 = （Spring Boot + SpringBoot + Vue + Vue3 + 前后端分离） * （管理系统 + 系统设计与实现 + Web系统）
```

**5. 成果展示 / 孵化方向**
```
主题 = （成果展示 + 展示平台 + 创新创业孵化 + 大学生创新创业 + 第二课堂） * （系统 + 平台 + 设计）
```

**6. 教育管理（用于补充综述背景）**
```
主题 = （高校学生社团 + 大学生社团） * （管理 + 建设 + 育人 + 信息化）
```

## 四、按文献类型检索建议（保证 ≥3 种）

| 类型 | 知网入口 | 关键词补充 | 目标条数 |
|---|---|---|---|
| **学术期刊** | 高级检索 → 文献类型=学术期刊 | 上面 A/B 组关键词 | 10–12 条 |
| **学位论文（硕士）** | 高级检索 → 文献类型=学位论文 | 关键词后加「设计与实现」「的分析与设计」 | 4–5 条 |
| **会议论文** | 高级检索 → 文献类型=会议论文 | 加「信息化」「教育信息化」「计算机应用」 | 1–2 条 |
| **专利 / 标准（可选加餐）** | 知网「专利」/「标准」库 | 社团管理系统、学生活动管理 | 1–2 条 |

> 学位论文检索小技巧：知网学位论文库里，「高校社团管理系统」相关题目多形如
> 「基于 XXX 的高校社团管理系统的设计与实现」——直接搜 **篇名 = 社团 \* 设计与实现** 命中率高。

## 五、筛选设置（务必勾选）

1. **发表时间**：2023-01-01 ~ 2026-12-31（知网高级检索「发表时间」区间）。
2. **来源类别**（可选，提高质量）：北大核心 / CSSCI / 科技核心（CSCD）——若数量不足再放开。
3. **排序**：按「相关度」+「发表时间」各检索一遍，优先取近三年。
4. **去重**：同一篇被期刊/学位论文重复收录时只保留一条。

- 切勿直接把关键词答案当作文献条目使用；每条文献的**作者、期刊、年、卷(期)、页码**都以知网导出的结果为准。
