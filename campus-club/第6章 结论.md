# 第6章 结论

本文针对校园社团成果信息分散、展示渠道有限、孵化机制不完善等问题，设计并实现了校园社团成果展示与孵化系统。系统采用前后端分离架构，Web 端基于 Vue 3 与 Element Plus 构建并配套微信小程序，服务端采用 Node.js 与 Spring Boot，数据库为 MySQL；围绕成果上传与展示、评分与评审、孵化管理、资源对接等功能，构建了"成果上传—展示互动—评审孵化—资源对接—比赛推荐"的完整业务闭环，面向六类角色提供差异化服务。系统覆盖 30 个核心用例，功能测试通过率 87.5%，非功能测试通过率 85.2%，主业务流程均可正确运行，研究目标已基本达成。

本研究将社团成果的展示与孵化纳入同一平台管理，使成果由静态陈列转变为可评审、可对接、可推荐的流转过程，为高校社团管理信息化提供了可落地的实现方案，在提升管理效率与促进成果转化方面具有实践价值。

受时间与条件所限，研究仍有不足：一是访问控制仅在客户端实现，服务端未校验令牌与数据归属，口令与敏感配置未加密存储，安全性有待加强；二是业务服务使用单条数据库连接，未引入缓存与连接池，高并发承载能力有限；三是设计中的全文检索、对象存储与邮件通知尚未实现；四是性能测试在单机环境完成，与真实校园网络存在偏差。

后续研究可从三方面推进：一是完善服务端鉴权与权限模型，实现口令哈希存储与敏感配置外部化，并部署 HTTPS；二是引入 Redis 缓存、数据库连接池与全文检索组件，优化并发性能与检索体验；三是建立成果标签体系与推荐算法，实现成果与企业资源的智能匹配，为社团孵化提供决策支持。
